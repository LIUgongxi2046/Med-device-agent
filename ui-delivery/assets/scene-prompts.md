# 工作台场景插画

生成工具：内置 `image_gen.imagegen`。每个场景独立生成一张图片，用于工作台卡片和能力说明弹窗。

## 共用提示词

生成单独一张用于医疗器械企业 Agent 工作台的精致场景插画。横向画布 1536×1024，3:2 比例。统一风格：高级企业软件产品插画，正交等距 3D 视角，哑光白色陶瓷和半透明蓝色亚克力材质，浅冰蓝色纯净背景 #F3F7FC，光线从左上照射，柔和接触阴影，低饱和蓝色 #1768C4 为主色，少量青绿色或淡紫色辅助。主体居中，占画布约 65%，四周至少 15% 留白；画面轻盈，形状精确，具有清晰空间层次。不要人物、机器人、徽章、标题、数字、Logo、水印、UI 界面、外框或多宫格。除场景中特别指定的字母以外没有文字。
