# PRD V1.3.0 字段与真实资料核对

核对日期：2026-09-28。需求依据：`PRD.md` 第 8.5.2—8.5.9 节及 AC-45—AC-57。设计入口：工作台或资料中心的“打开真实公开资料”；直接地址参数为 `?revision=prd-v13-fields&scenario=public#human-review`。

## 目录与字段

申请目录保留六类、38 个官方二级节点，数量分别为 7、6、8、3、4、10。质量体系中的 6.1 为综述，6.2 为章节目录；设计开发、采购、生产服务与监视测量设备在字段模型分别保留。目录位于项目详情及撰写页右侧。首次非 IVD 目录的项目适用性需要注册人员确认。

| 文档类型 | 字段组数量 | 核对内容 |
| --- | ---: | --- |
| 产品技术要求 | 8 | 编号及申请阶段、名称、型号划分、软件版本、性能指标、检验方法、IVD 方法、术语与附录；指标与方法保存对应编号及型号 |
| 综述资料 | 9 | 概述、产品描述、型号对照、包装、研发背景、适用范围、禁忌警示、上市历史、配合使用 |
| 说明书 | 14 | 主体、标识、注册证明、性能组成用途、警示、安装操作、维护储运、日期期限、更换复用、符号、修订及其他标注 |
| 标签样稿 | 3 | 标识主体、期限使用条件、符号警示；保留最小销售单元样稿位置 |
| 基本原则清单 | 1 | 官方五列独立显示；条款支持增加记录；客观证据必须记录文件及位置 |
| 风险管理 | 1 | 危害、过程、损害、控制、实施与有效性证据、剩余风险、说明书警示与责任人员 |
| 研究报告 | 3 | 研究设计、结果附件、条件性研究；方案和结果分别维护 |
| 临床评价 | 8 | 描述、范围路径、产品对比、数据文献、试验、免评价对比、结论、人员与附件 |
| 质量体系 | 8 | 生产、文件职责资源、设计开发、采购、生产服务、监测设备、分析改进、核查文件 |
| 变更资料 | 1 | 原证及历次变更、变更前后、原因、型号、风险与验证、临床及说明书体系影响 |

数据模型合计 11 个文档类型、57 个初始字段组，保存于内部审查 JSON。未提供原件的字段保持空白或待补证。当前页面通过连续正文、折叠证据和标注组织人工工作，字段管理不作为正文旁的独立表单；完整交互见 `document-reading-design.md`。

## 人工操作与状态

字段模型保留未填写、待补证、存在冲突、待审查、已确认、不适用六种状态。真实字段确认需要核准来源、理由、人员与明确属性；当前文档页面通过正文标注记录待处理事项，专业适用性与正式授权服务未接入。

技术要求的拟申请编号允许留空，其他字段不得使用任务编号填充。性能指标与检验方法需要记录对应型号及条件。当前页面不根据普通文本自动判断方法科学性、标准适用性或证据充分性。

正文修改会清除当前任务审查确认和来源核验。审查页面只读全文并记录带原文位置的标注，支持定位、回复和解决。完整的权威事实传播、跨文件影响位置自动识别与授权服务仍未接入。

## 检查证据

- `check-prd-v13.mjs`：38 项目录、57 组内部审查记录、公开项目与正式签发限制。
- `check-document-reader.mjs`：真实图片、原件页码、证据折叠、右侧清单、全文标注、定位回复与六种宽度。
- `check-public-originals.mjs`：原件与预览 SHA256、两个 PDF 共 29 页非空文字及标题。
- `check-interactions.mjs`：项目、资料、Gru、模型配置、Agent、复杂案例与注册图文交互回归。
- `check-ui-quality.mjs --verify`：DOM 字号、纯色文字对比度、焦点与宽度检查；不包含人工视觉审查。

客户实际说明书、检测报告、结构图、设备页面、标签和授权资料尚未提供。客户项目字段不能由该公开参考案例替代。页面会话数据在刷新后恢复初始状态。
