## 检查证据

`check-prd-v12.mjs` 使用工作区 PRD.md、界面规范.md 和 asset-manifest.csv 验证文件读取、重复识别、资料集历史、检索范围、引用保护、能力发布条件、来源范围、停止反馈及固定成果下载。`check-interactions.mjs` 同时回归项目、审查签发、Gru、资料维护和模型 API 配置。字体、颜色与布局另由 `check-ui-quality.mjs` 检查。

能力登记与研究问题支持用户输入；复杂演示另由 `complex-demo.js` 按本轮授权提供，保留演示标识。不会生成真实审核成功或模型执行结果。原型数据保留当前页面会话，刷新不会恢复本次新增业务记录。

持续研究区域将问题、协作、记录和成果置于正文旁；AC-38 与 AC-40 相关操作增加 Gru 要求登记和人工决定记录，AC-39 通过演示案例呈现前置关系，AC-42 支持当前页面成果预览与下载。`check-continuous-workspace.mjs` 验证这些界面行为，真实服务验收状态保持 NOT_RUN。
