# 业务工作区界面规范

沿用医疗设备智能工作站品牌、若依导航、Element Plus组件与现有图标。页面采用清晰标题、独立业务分区、适度留白和明确操作层级。使用当前系统字体，不新增图像或字体资产。

页面正文14px、行距1.6；主标题26px，移动端22px；区块标题18px，字段分组15px，帮助文字12px。正文、辅助文字、表面、边框和反馈颜色全部引用Element Plus语义变量，随明暗主题变化。

页面边距桌面28px/32px，移动端16px；区块间距24px，表单列间距24px，字段间距22px。业务区块圆角12px，控件8px；筛选栏使用浅色表面。桌面控件最小40px，移动端44px，保留键盘焦点。错误文字处于字段正常布局内，长文字换行，不遮挡下一字段。

筛选表单支持换行并与查询操作排列；常规长表单使用双列，长文本和确认字段占据整行，移动端单列。既有字段组件继续使用原布局和实际字段，统一标签、控件与帮助文字。完整源码清单为form-source-map.csv，源码编译证据与实际交互证据分别登记。

模型配置包含目录、历史版本、草稿编辑与保存区。草稿字段按照供应商与模型、访问凭据、能力与调用限额、价格与数据政策、请求参数协议五个分区排列。保存按钮使用主操作颜色，清除操作使用普通按钮；批准、连接验证及运行启用保持原业务含义。

组织入口固定于顶部导航。桌面沿用50px顶部与34px标签页，移动端导航104px、标签页34px，内容从138px之后显示。组织候选仅来自当前有效成员，使用现有真实tenant_id。组织切换确认说明全局范围及未保存输入处理；选择和未完成请求均保留既有服务端校验。

常规菜单切换期间保持侧栏组件、展开状态和滚动位置。身份核查期间暂停访问资格；收到相同主体及完整授权后恢复资格，授权内容变化时重新登记路由。明确失效与注销清除权限。业务依赖错误显示错误信息，保留仍然有效的组织会话。

不适用图像资产导出、额外产品页面和全新品牌方向；本次属于已有工程的IMPLEMENT。用户禁止主动视觉功能，使用DOM、计算样式及真实操作检查，不声明截图或视觉比较已经执行。
