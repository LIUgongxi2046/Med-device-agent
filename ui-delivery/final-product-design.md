# 目标产品完整设计

日期：2026-09-28。设计依据：客户需求初次沟通、当前 PRD，以及用户确认的导航、阅读与人工审查方式。

## 交付范围

主入口为 `设计稿.html`。工作台的七类场景分别使用独立插图，提供创建任务和能力说明两个入口。能力说明展示适用工作、所需资料及交付内容；创建入口展示输入确认、章节配置、执行、检查和审查过程。

界面继续采用若依 Vue3 的深色侧栏、蓝色主操作、标准表格和表单。核心功能、平台管理、系统管理保持独立分组。正文阅读区域、右侧目录、折叠证据、选区标注、项目层级导航沿用已确认的交互。

## 文档类型与共同交互

产品技术要求、注册文档目录、综述资料、说明书、标签样稿、基本原则清单、风险管理、研究报告、临床评价、质量体系、变更资料、延续资料及注册资料总稿，共用配置、撰写与核验、审查与签发三个步骤。

每种类型使用独立目录。模板维护支持四种处理方式：指定资料取值、按法规或模板填写、限定范围编写、严格字段核验。修改章节配置后形成待审核版本，发布后可以创建任务。已创建任务保存当时的输入依据。

## 状态与人工动作

| 对象 | 正常过程与成功状态 | 人工动作和限制 |
| --- | --- | --- |
| 任务输入 | 填写 → 确认版本 → 创建 | 核对目标、资料范围与模板；待审核模板不允许新建任务 |
| 执行 | 依据确认 → 提取 → 编写 → 检查 → 审查 → 成果整理 | 查看进度、暂停、继续；继续时恢复暂停前状态 |
| 文稿 | 草稿 → 保存 → 核验 → 审查 → 签发 | 正文、图片与引用修改后重新核验；未满足来源条件时禁止签发 |
| 检查问题 | 待处理 → 定位 → 修订 → 复查 | 记录处理依据；正文或引用未完成处理时仍显示待处理 |
| 严格字段 | 待确认 → 原值与条件核对 → 人工确认 | 确认人员必须核对指定资料；当前版本确认不延续到后续修订 |
| 意见 | 待处理 → 回复 → 解决 | 保留原文位置，支持文字与图片标注；退回后重新提交审查 |
| 模板、规则 | 已发布 → 修改 → 待审核 → 发布新版本 | 审核适用范围、处理条件和章节来源；保留版本记录 |
| 法规影响 | 查看版本 → 查找引用任务 → 保存决定 | 已签发文档保留原版本；人工决定是否创建修订任务 |
| 评测 | 选择版本 → 选择样本 → 五维评分 → 发布决定 | 评分范围 0—100；按版本与样本保存；发布保留依据 |
| 反馈 | 待审核 → 已确认 → 已纳入修订 → 已完成评测 → 已发布 | 指定处理对象；每次阶段变更记录决定依据 |
| 成果 | 预览 → 导出 → 归档 | 正文、检查、审查与来源分别查看，归档记录固定版本 |
| 授权 | 添加成员 → 指定范围与动作 → 保存 | 读取、编辑、审核、签发分别授权，保留调整依据 |

## 设计数据来源

`scene-results.js` 保存目标成功状态的编辑设计内容。注册文档、质量检查、法规影响中的完成状态和处理记录属于设计样例，不能作为已执行的医学、法规或者产品审核记录。

报告、翻译、市场研究和问答复用了工作区 `public-reference.js` 中的 REMI 公开资料摘录。产品名称、组成和企业名称来自已有公开参考资料；本次没有新增产品性能事实。翻译文本为展示双语交互编写的译文。市场结果明确保留没有证据支持的范围，不编造市场规模、价格或销量。

`final-product.js` 中的评分、采纳率、退回率、费用、私有模型连接与验证状态属于目标界面样例。地址使用保留的 `.example` 域名，不发送模型请求。费用展示采用输入 ¥12 / 百万 Token、输出 ¥186 / 百万 Token 的设计费率，本月输入 1,240,000 Token、输出 310,000 Token，合计 ¥72.54；这些数值不代表实际用量或商业报价。

初始评分用于展示相同评测范围的版本比较。用户录入的评分按配置版本和样本保存，同版本的页面均值根据当前录入记录计算。正式统计需要明确固定样本集、权重、计费来源及统计时间；这些属于开发与业务验收事项。

## 开发交接

页面可操作范围包括本地表单、版本记录、资料查看、图文阅读、标注、下载与状态切换。页面刷新恢复预置内容。目标成功状态的展示不会调用外部模型，不代表服务连接、解析、语义检索、任务执行、授权隔离或电子签名已经完成。

Gru 的可操作回答引用当前选择资料的摘录，保留版本、原文位置和处理入口；修订内容由阅读区与确认操作共同处理。任意问题的语义理解和自动改写质量需要接入模型后另行验证。

开发需要接入企业身份与权限、模型和工具服务、解析与索引、任务调度、版本存储、审计、统计及正式文件转换。HTML 导出可操作，PDF 通过浏览器打印；正式 DOCX、页码、目录与申报格式需要文档服务验收。

本说明负责记录设计数据和开发边界。产品页面保留业务名称、操作与状态，交付限制集中保存在设计文档中。
