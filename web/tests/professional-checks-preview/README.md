# Professional checks preview

Actual Vue component, isolated simulated data; no router, API, credentials, professional conclusion or business writes. Run from web: `node node_modules/vite/bin/vite.js --config tests/professional-checks-preview/vite.config.mjs`. Open `/tests/professional-checks-preview/index.html` on port 18089.

Exercise N05/N06/N07 stage navigation, missing-result counts, raw severity filters/search, location event, dirty/stale and candidate switches, and unavailable-result mode. All consequential controls remain disabled. Published ReviewFindings, AssemblyManifest, CheckResultRequest and CheckReceipt are presentation inputs only. A public artifact or SUCCEEDED receipt never authorizes review or signature. Unknown cross-file detail/complete requirements/current validity are explicit.

Focused tests: `node --test tests/frontend/document-professional-checks-checks.mjs` from repository root. Build an actual-Vue standalone preview from web with `node tests/professional-checks-preview/build-standalone.mjs` (only when the shared build slot is free). This is not live authenticated integration or backend acceptance.
