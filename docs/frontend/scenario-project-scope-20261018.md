# 场景目录：真实项目范围选择（2026-10-18）

## 本次实现

- `web/src/views/medical/scenarios.vue` 复用现有 `ProjectScopeSelect`。选择项来自 `GET /api/projects` 的获授权项目目录，分页由用户显式触发；支持保留/输入已知项目标识。
- 查询继续调用 `listScenarios` / `GET /api/scenarios`，不引入新后端接口。所选项目、目标文档条件、数据水位及下一页游标沿用原 API 校验。
- 项目或文档条件变化时，同步中止旧请求并清空旧目录；用户重新查询后才显示新范围结果。
- 会话或授权摘要原位变化、页面离开及隐藏时清除旧数据。请求代次、会话身份及 AbortController 共同隔离迟到响应；授权变化同时重新挂载项目选择器，移除其旧项目选项。
- 读取失败显示错误并清空旧结果；未取得当前范围确认结果时显示“版本总数未知”。确认的真实空结果才可显示服务端返回的零总数。
- 明确区分配置状态、规格核验与真实任务入口；保留 `UNVERIFIED` 和服务端 `task_entry=null` 边界，不添加执行按钮，不将发布记录视为正式准入。
