# 前端操作与服务岗位说明

核查日期：2026-10-14。本文对应当前`web/`源码和已提供的公开接口。SIMULATION输入只能用于获授权开发检查；正式专业资料、业务批准和客户验收按原任务记录独立登记。页面是否允许操作以当前会话及服务端许可为准。

## 账户、企业与项目

1. 在`/access`登录账户，成功后进入工作台。`/account`显示本人资料和版本，资料修改及密码操作沿用原表单。当前头像上传仍等待对应接口接入。
2. 页面中的企业选择器只列出本人有效成员所属企业。选择目标以后点击“确认选择企业”，重新读取的上下文及授权水位确认成功以后进入该企业业务。
3. 企业登记使用`/enterprises/registrations`；人工审查使用`/enterprises/registration-reviews`。审查人员需要获准治理权限，按原申请、版本、完整范围及依据填写决定。
4. 企业岗位位于`/enterprises/roles`，成员、邀请及授权位于`/enterprises/members`。邀请接收人员在`/member-invitations/acceptances`填写实际凭据；接受邀请以后仍需明确选择企业。秘密凭据不使用URL传递。
5. 在`/projects`读取获授权项目。创建项目需要实际负责人、建档依据及理由；修订属性保留原版本，UNKNOWN需要明确未知原因。项目状态决定提交实际当前修订，成功以后重新读取项目状态和允许动作。

## 资料维护

资料中心位于`/library`，项目详情提供项目上传入口。逐文件填写完整原件声明及权利范围，传输完成以后查看原上传及完成操作。“查询固定处理结果”读取服务器保存的来源关联、当前权利和独立处理尝试，展开文件记录可以查看全部解析版本、索引结果、人工核准依据和完整失败清单。接收、传输、解析、索引和人工核准分别核查；完成上传不能判定后续处理已经完成。固定来源链接采用服务器返回的source_version；登记时权利版本与当前权利版本分别显示。

`/library/processing`显示实际处理队列。失败项重新处理需要当前权限、项目及完整依据，按原操作查询执行结果。`/library/versions/:sourceVersion`读取固定历史版本、原件、解析内容和Locator；原件阅读提供DOCX、PPTX、PDF、XLSX、CSV、Markdown及TXT组件。无法取得或核验原始位置时停止正式引用。

固定来源页面的“索引构建记录”需要填写明确执行项目编号，再读取该来源和项目的完整清单。构建结果、当前索引状态和投递状态分别显示；已撤回索引保留原构建结果，当前没有记录时显示实际空列表。项目编号改变会清除原结果，刷新以后需要重新填写并查询。

来源核准人员检查完整原件、固定解析版本、来源权利、依据及拟用范围，填写明确决定和理由。文件夹、标签、收藏、项目绑定、引用查询和生命周期操作沿用资料维护页面。永久清理状态只根据服务端的完整存储回执呈现。

`/library/versions/:sourceVersion/rights`提供来源权利审查。批准需要填写完整用途、动作、提供方、区域、UTC期限、权利人、许可、环境、分类和固定授权文件版本及摘要。退回和撤销使用各自明确决定。读取固定审查以后核查来源、原权利、修订及授权文件清单，填写理由并确认，再提交决定。许可输入改变会清除原审查；成功以后重新读取会话、原操作和当前来源。

权利请求结果未知时使用“查询原请求”；原完整DecisionInput及摘要一致后，使用原请求编号读取固定回执或恢复发送。浏览器存储只保留人员、企业、目标、原上下文、请求编号和摘要；许可正文及理由没有保存在其中。原记录EXPIRED以后需要明确结束原请求才能开始新的审查。

固定来源页面提供“读取与核准结构化字段”，进入`/library/versions/:sourceVersion/exact-fields`后选择适用项目及已核准解析和READY索引。读取真实解析片段，填写开始与结束Unicode位置，核查完整原值，再加入字段清单。五类字段分别为器械型号、产品技术要求编号、文件文号、标准编号和标准年代号；人工别名需要独立审核理由。首次核准填写修订0，后续读取完整当前清单并使用其修订。固定字段版本可独立读取，保存后重读原操作和完整清单。请求结果未知时通过原字段请求查询及完整原输入恢复。

`/library/search/exact`提供核准字段等值查询。选择获授权项目及字段类别，完整填写原值或人工别名；查询保留空白、大小写和Unicode表示，正文没有进入URL或浏览器存储。命中呈现所有匹配字段、原文及完整来源身份，固定历史使用retrieval_id和页码；打开命中核验同一解析片段和位置摘要，并展开完整原文与Locator。当前权利、资料核准或适用状态变化后重新核查读取许可。

页面准入读取失败时，`/session-recovery`显示实际错误代码及请求编号。点击“重新读取会话并继续页面”完成会话、企业候选及权限重新核查，继续当前内存保留的原页面；刷新该恢复页面后可以通过项目列表或资料中心重新进入。原业务请求安全元数据继续保留，恢复入口没有自动重试。

`/library/collections`及其创建入口维护固定成员版本；已有任务仍采用自身固定快照。`/library/search`保存查询于受控内存，历史读取使用retrieval_id；翻页保持同一检索及水位。`/library/artifacts`读取成果，转存需要明确当前成果、许可、项目和来源声明，成功结果仍为待核验来源。

## 模板与人工计划

在`/templates/new`选择完整文档类型、申请路径及目录规范。结构化编辑入口提供目录、全部十一种字段、重复表格、附件及跨文档规则。每项保留稳定标识、完整条件、证据规则、输出位置及依据；Decimal上下限和U64数量使用十进制字符串。取消修改保留原定义，移除需要确认具体对象。完整JSON输入、导入和整体校验仍可使用。

模板保存以后需要通过`/templates/:templateId/approval`读取完整固定定义及审查依据，由获授权人员明确决定。项目适用模板位于`/projects/:projectId/templates`；UNKNOWN保持待确认，适用判断不能替代人工批准。

在项目任务入口选择真实责任人员、固定发布版本、核准模板和资料范围。四种资料范围、明确清空和关闭网络分别生效。创建后重读任务；`/projects/:projectId/tasks/:taskId/config`提供当前任务、完整缺项及人工计划编辑。目录、章节、研究问题、责任和证据要求完整保存，确认及退回使用原版本和明确理由。运行启动、人工继续及输入变更仍等待完整公开接口。

## 正文、选区与成品

任务当前状态中的获授权文稿提供正文读取。文字、字段、表格、图片说明及LaTeX公式按稳定节点编辑；数值保留原字符串。字段修改需要单独确认，正文保存需要修订理由。保存期间继续编辑属于后续修改；并发变化通过原版本、服务器版本和当前编辑比较，逐项选择处理内容。

“全文阅读、目录与正文选区”提供当前正文目录、连续阅读、文字选择、固定图片身份和表格单元格选择。键盘文字选择按Unicode字符位置填写起止，结束位置不包含该字符；emoji、组合字符和换行保持原值。未保存选区明确标记，保存以后重新选择才能提交核验或审查。当前选区组件尚未连接Gru和专业审查写入接口。

历史阅读需要实际固定正文版本。读取以后核查版本及摘要，目录定位保持该历史正文。证据面板使用固定来源、解析版本及Locator打开原文；图片像素内容仍需要公开受限制品接口。

文稿中的成品区域读取实际导出依据及记录。不同格式独立查看处理状态和核验结果，授权下载核查原字节。正式签发、专业检查、人工审查、再次认证和候选部分采用尚未完成接口集成，不能将内部导出视为正式签发成果。

## 模型、场景与管理入口

`/agents/budgets`提供预算读取、建立、追加批准和历史版本。金额、Token、预留及未知费用保持原含义；批准预算以后运行仍需明确继续。模型配置、实际连接验证、Agent能力七项标签、评测发布和运营统计等待完整接口交付。

`/scenarios`读取当前场景目录及具体规格缺项。法规比较、报告生成、翻译、市场分析、多模态问答分别需要完整规格和发布准入。客户B/S连接还需要客户接口及读写授权。

十八项系统管理功能沿用原若依页面和环境菜单。服务监控及开发工具使用对应实际权限；平台管理员身份不自动授予企业专业资料权限。SaaS、私有化和服务岗位接收需要目标环境及批准范围。

## 未知结果与问题处理

保存结果未知时保留原请求编号、目标、版本和原参数。FOUND读取原操作及实际对象，NOT_FOUND保持原键，EXPIRED禁止原请求重新发送，PROCESSING查询对应原操作。正文、查询、理由及秘密保留在受控内存；身份、企业、项目或页面变化以后重新核查当前对象。

提交问题时提供页面入口、允许披露的请求编号、错误代码、时间及当前版本，不附带密码、邀请凭据、秘密或完整专业正文。资料维护人员处理原件及来源声明，模板维护人员处理固定定义，专业审查和签发人员按实际授予职责操作，环境维护人员核查源码、制品及部署身份。接收责任人员及完整操作验收由对应IMP记录维护。
