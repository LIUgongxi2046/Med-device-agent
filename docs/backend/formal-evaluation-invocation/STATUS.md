# Independent formal evaluation invocation adapter

C07 implementation source is wired through the independent EVAL lane. No test, full build, database, runtime, provider, deployment, or network execution has been performed for this slice. A narrow Java production-source compile is the only verification so far.

The invocation lane binds a private current independent evaluation session and a separately observed SDK request to the actual approved physical exact input. It uses existing RequestParameters purpose `EVALUATION`, current model.send purpose `EVALUATION_RESULTS`, and execution identity `SYSTEM_JOB / EVALUATION_VERIFICATION`. These are three different existing contracts, not interchangeable labels.

The adapter uses original 076 dual budget reservations, the durable CAS dispatch journal, authenticated provider capture, two physical registered receipt objects, and accounting. The final stop proof is privately constructed only from successful, settled originals. Unknown transport outcomes do not release reservations, invent receipts, or authorize another provider dispatch. Recovery replays held original bytes through the original authenticated adapter only.

Source, approved model/credential, role, observed request, physical input, original price read and retention are rechecked. Source MODEL_SEND is checked independently of REVIEW and per actual business/governance purpose. Expected evaluation outputs are not sent to the provider.

Ordered rounds now consume actual original 076 model results/accounting/capture pins and immutable 150 tool receipts, including original history-prefix validation. Every call has a separate 149 physical exact-input object, independent actual SDK observation and actual tokenizer result. The approved tools are preserved losslessly. Tool response transmission receives a separate fresh provider-specific source-send check. Final completion exposes the full verified invocation list and reparses the actual final model result for historical business checks.

The production delta, 149 producer, 150 tool receipts/controller/configuration, and necessary 147 dependency sources passed a narrow Java compile on 2026-10-20. This is compilation only, not behavioral validation. Deferred tests were added as source and were not compiled or run.

Broader node input producers and genuine SDK relay integration remain owned by the node lane. The invocation adapter requires their actual fixed input/evidence contract and rejects missing/unsupported input and tool histories. This is not a claim that all A12 cells, F1/F2, tools, or acceptance are complete. Database migration, integration, gateway execution, retry/concurrency behavior, and security acceptance tests remain deferred.
