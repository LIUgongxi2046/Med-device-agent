# N05 independent review core

Code-first implementation, with test sources written but not executed. Full build,
SQL execution, provider calls, runtime and integration verification remain pending.

## Execution and authority

Preparation consumes only genuine committed N04 chapter candidates, checks the entire
run step capacity before any input upload, and materializes a distinct N05 input.
Target authority verifies immutable candidate and body identities. Current source
rights and approved frozen rule ancestry are checked independently. N05 has its own
producer governance, session, exact typed input, physical original source/rule reads,
076 invocation lineage, findings and coverage registrations. Writer support links
are target data, never independent evidence of support.

The normalizer enforces the complete fixed claim/rule universe, exact body anchors,
and actual text/field/node coverage. Missing access, locator or complete source reads
cannot become support. Contradicted, unsupported, uncovered and blocked checks remain
explicit findings. Applicable deterministic completion rules cannot be overridden by
a model PASS. Actual source access alone never implies semantic support.

AT07 saves a CANDIDATE check, physical ReviewFindings, separate coverage artifact and
candidate-only issue proposals. Its target_revision is the body artifact identity.
Any incomplete coverage, issue, contradiction, insufficient claim or failed/blocked
rule yields WAITING_INPUT. SUCCEEDED is check execution only; professional_approval
is always false. No document adoption, signing or issue resolution is performed.

Original recovery verifies immutable dispatch, physical output bindings, invocation
and independent-read receipts, status recomputation, audit/outbox and proposal hashes.
It returns original receipts only, without restoring current source or send authority.
Current downstream assembly consumption is a separate N06 authorization seam.

## N06 current-consumer seam

TaskSourceVerifierCommittedReviewAuthority reauthorizes the genuine N05 input, source
rights and original rules, then consumes a real passing stage commit and independently
verified original physical outputs/provenance. It also compares current issue/evidence
watermarks. Its private CommittedRead permits only the exact findings/coverage pair
through normal current artifact ownership and grant checks; generic control scope is
not expanded. The authority exposes exact object references and expected payloads for
N06 physical context reads, without minting a new N05 invocation or lease.
