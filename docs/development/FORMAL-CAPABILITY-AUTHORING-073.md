# 073 正式能力草稿登记

## 已实现

普通业务页面：`/agents/capabilities`、`/agents/capabilities/new`、`/agents/capabilities/:recordId`。目录、登记、固定详情使用实际后端合同、实际已登记制品目录、固定 Schema 引用与摘要；没有手工构造假制品或把模拟能力改名为正式能力。

首版支持 ROLE 与 PROMPT。ROLE 权限使用真实 RuntimeRoleScope，精确到资源、动作与用途，每一项由后端当前权限再次验证。PRODUCTION 表示声明的目标执行模式，登记状态仍是 DRAFT；它不批准 Agent 发布，也不授予执行权限。现有制品目录只证明可读取的登记元数据，专用 ROLE/PROMPT 包内容的执行解释与资格核验由后续运行链负责。

后端在单一企业事务内持久化真实版本、原请求、操作回执、审计与事件。读取核验原记录、完整摘要、当前来源权利和权限。统计策略写入不包含在073公开接口中，保留表不意味着该功能已经启用。

## 恢复与并发

提交前将完整规范请求、摘要、原 key、原身份与上下文保存到当前浏览器会话存储；存储失败不提交。未知结果只按原 key 只读查询，再核对实际操作、类型回执与固定记录，不能从列表猜测成功，也不自动换 key 重发。

身份、上下文、页面或可见性变化会中止并丢弃迟到显示；写请求持有自己的全局锁。任何声明修改都会撤销勾选确认。未知、失败、过期或互相矛盾的回执保留原证据，不通过清空记录假装可安全重试。

## 启用与验证

`medical.agent-authoring.enabled` 默认关闭。需要真实登记依赖、明确的包 profile 与当前来源/权限；代码不生成这些授权。服务状态接口始终要求登录，状态可用不等于用户有权执行。

- 正式12模块 Maven：47项专项 Java 测试通过。
- 前端：41项实际 TS/Vue/路由/请求拦截器测试通过。
- 073迁移：4项实际 JSQLParser/SQLGlot 测试通过。
- 新增真实来源制品目录 Schema 白名单项，修复候选读取被前端自身合同门禁误拦的问题。

尚未据这些专项测试声明真实 MySQL、对象存储、浏览器视觉验收或完整 Agent 发布/运行通过。
