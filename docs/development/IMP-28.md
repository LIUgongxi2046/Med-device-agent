## 当前源代码范围

正式评测保留固定输入/候选、实际执行原件、独立完成/评分、接受和发布消费者，历史事实读取与当前发布资格分离。模拟 API 的结果必须显式标记，不能成为正式提供方、专业证据或真实评测通过证明。

BusinessOperationsService/Controller/Schema 实现企业与项目统计、明确分母与未知费用、批准的报告属性维度、独立原记录授权与安全 CSV。OperationsFeedbackService/Controller 的 Agent 反馈闭环绑定真实修订、评测和发布；KnowledgeFeedbackService/Proofs/Controller 的知识与规则反馈绑定实际变更提案、接受、应用及当前源/规则批准，不能推断下游文稿已重新确认。细节见[B30 运营反馈交接](B30-OPERATIONS-FEEDBACK-20261021.md)。

管理后台的固定操作、权限与环境、副作用、受控表单发布及独立发布清单见[B30 框架交接](B30-framework-bindings-20261021.md)。医疗模式明确不开放任意 SQL、服务器路径生成、反射任务、全缓存清空和日志永久清理；原非医疗功能保留。旧批准不能自动授权改变后的能力或插件版本。
