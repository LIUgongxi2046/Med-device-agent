### 4.2 本轮直接消费的公开接口

| 方法与路径 | 输入或查询要点 | 成功响应 |
| --- | --- | --- |
| `GET /api/uploads/{uploadId}/status` | 原上传UUID；当前会话和上下文 | 200，完整上传结果 |
| `GET /api/source-versions/{id}/index-builds` | 必需`project_id` | 200，完整索引清单 |
| `POST /api/source-versions/{id}/rights-reviews` | `PreviewInput`，完整决定及proposal | 200，固定审查预览 |
| `POST /api/source-versions/{id}/rights-decisions` | `DecisionInput`，原审查摘要、权利依据及修订 | 200，完整决定回执 |
| `POST /api/source-versions/{id}/exact-fields` | `PublicationInput`，完整固定依据及fields，首次`expected_revision="0"` | 201，`PublicationReceipt` |
| `GET /api/source-versions/{id}/exact-fields` | `project_id/parse_version/approval_revision` | 200，当前完整`Manifest` |
| `GET /api/source-versions/{id}/exact-fields/{revision}` | `{revision}`为`field_revision` UUID；必需`project_id` | 200，指定固定`Manifest` |
| `POST /api/retrievals/exact` | `SearchInput`；明确项目、field_kind、完整query及purpose | 201，`COMPLETED Operation` |
| `GET /api/retrievals/exact/{id}` | 固定retrieval_id；`page/page_size` | 200，固定`Page` |

接口使用当前Cookie会话、`X-Schema-Version: 1.0.0`及`X-Context-Revision`；写入按对应Controller校验CSRF和`Idempotency-Key`。成功Envelope及完整ErrorResponse由既有公共定义提供，Schema拒绝未知字段。资源修订和数量按十进制字符串传递，原始Decimal保留原值，时间使用规定的UTC表示。

请求与响应的唯一字段依据位于`business/medical-persistence/src/main/resources/`中的`source-upload-status.schema.json`、`source-index-view.schema.json`、`source-rights-decisions.schema.json`及`source-exact.schema.json`；前端在`protocol.ts`登记并执行完整校验。接口调用方读取对应Controller、Service及`web/src/api/medical/`封装，完整API与设计继续引用[接口补充设计](../backend-design/接口补充设计.md)和[OpenAPI](../backend-design/interfaces.openapi.yaml)。

## 8. 接手顺序与交付依据

1. 读取本文件、[开发索引](development/index.md)、原前端计划和对应IMP记录，核对当前工作区与正在使用的环境。
2. 当前可直接执行的下一项为使用当前Chrome重新验证BROWSER-31覆盖的组合。按第5节完成当前制品和独立浏览器检查，更新对应主记录中的实际结果及工具身份。
3. 逐项检查第6节的后端交付条件。条件满足的业务继续完整前端实施与实际验证；输入、字段或状态未知的部分保留具体缺项，独立工作继续执行。运行与模型配置交接分别读取[IMP-12](development/IMP-12.md)、[IMP-27](development/IMP-27.md)、[MODEL-CONFIGURATION-01](development/MODEL-CONFIGURATION-01.md)。
4. 每项保存后查询原操作、重新读取固定对象，并验证冲突、撤权、刷新及未知结果恢复。依据实际检查更新唯一主记录和索引，功能任务按原完整条件验收。
5. 目标发布及岗位接收使用[IMP-40](development/IMP-40.md)、[IMP-41](development/IMP-41.md)、[IMP-42](development/IMP-42.md)和[制品环境说明](frontend-release-guide.md)。现有可复验制品与实际目标部署分别登记。
